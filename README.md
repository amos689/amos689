## 👋 About Me

I'm **Fanglei Liu**, from the **Master of Computing** program at the **Australian National University (ANU)**. My interests span **trustworthy AI, retrieval-augmented generation (RAG), knowledge graphs, LLM evaluation, and AI-assisted software testing**.

I explore how to make AI outputs easier to verify, from evidence-grounded retrieval and reasoning to software testing, data quality, and reproducible content analysis. I also build open-source research tools for academic figure generation, citation checking, and keeping manuscript claims aligned with experimental evidence.

- 🧠 **Research:** Trustworthy AI · RAG & Knowledge Graphs · LLM Evaluation
- 🌱 **Applications:** AI-assisted Testing · Data Quality · Human–AI Evaluation
- 🧰 **Engineering:** Python & SQL · React Interfaces · Reproducible Research Workflows
- ❤️ **Open source:** [Academic Figure Generator](https://github.com/amos689/Academic-Figure-Generator-OpenAI), [paper-preflight](https://github.com/amos689/paper-preflight), and [PaperDelta](https://github.com/amos689/paperdelta)
