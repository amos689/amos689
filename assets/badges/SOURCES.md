# Badge artwork and colors

The skill badges use brand artwork from [Simple Icons](https://github.com/simple-icons/simple-icons) and [Devicon](https://github.com/devicons/devicon), with dbt artwork taken directly from its documentation repository. Icons are monochrome for readability; badge backgrounds use the brand colors below. Header navigation uses a custom sky, mint, violet and pink palette.

SQL uses a generic database cylinder because the SQL language has no single vendor identity. The CSS3 badge retains the classic CSS3 shield.
